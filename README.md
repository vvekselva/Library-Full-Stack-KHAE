# Library Full Stack KHAE - Presenter

Instructor / Presenter master repository for the Library Full Stack Demo.

## Document Regeneration Quality-Control Workspace

This repository is the controlled workspace for regenerating the progressive student development guides.

The approved Student 01 Create Department guide is the Golden Reference. All regenerated documents must follow the repository Quality Gate and Generation Protocol before they can be marked complete.

### Repository control structure

- `golden-reference/` — approved reference artifacts used as the minimum quality baseline.
- `quality-gate/` — supporting quality-control material.
- `tasks/` — task-specific inputs, plans, intermediate work, and evidence.
- `output/` — generated artifacts that have passed the required generation stages; final approval status is tracked separately.
- `QUALITY_GATE.md` — mandatory acceptance criteria.
- `GENERATION_PROTOCOL.md` — mandatory process to follow while generating each document.
- `TASK_STATUS.md` — authoritative task and quality-gate status register.

## Hard completion rule

`GENERATED` does not mean `COMPLETE`.

A document is complete only after it has been generated, reviewed, corrected where necessary, visually inspected, compared with the Golden Reference, and recorded as `QUALITY GATE: PASS`.
